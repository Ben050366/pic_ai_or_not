# Vercel 部署指南

完全免费，无需绑卡！

---

## 🌐 Vercel 官网
https://vercel.com

---

## 📦 第一步：准备代码文件

把 `vercel-simple` 文件夹里的文件上传到你的 GitHub 仓库：

```
你的GitHub仓库/
├── package.json      ← 刚才创建的
├── index.html        ← 网页
└── api/
    └── detect.js     ← API接口
```

---

## 🚀 第二步：部署到 Vercel

### 1️⃣ 注册/登录 Vercel
- 访问 https://vercel.com
- 点击右上角 "Sign Up" 或 "Log In"
- 用 GitHub 账号登录（推荐）

### 2️⃣ 新建项目
- 登录后，点击 "Add New Project"
- 选择你刚才上传的 GitHub 仓库
- 点击 "Import"

### 3️⃣ 配置项目（重要！）
- **Project Name**: 随便填，比如 `ai-image-detector`
- **Framework Preset**: 保持 `Other`
- **Root Directory**: 保持为空（如果文件在仓库根目录）

### 4️⃣ 添加环境变量（最重要！）
- 找到 "Environment Variables" 部分
- 添加一个变量：
  - **Name**: `HIVE_SECRET_KEY`
  - **Value**: `6XRi12JquRoMFWJXC02tpw==`
- 点击 "Add"

### 5️⃣ 开始部署
- 点击 "Deploy" 按钮
- 等待 1-2 分钟

### 6️⃣ 完成！
- 部署成功后会显示你的网站地址，类似：
  - `https://ai-image-detector-xxx.vercel.app`
- 点击这个地址就能使用了！

---

## ⏸️ 如何暂停/删除网站

### 暂停（暂时关闭）
- 访问 https://vercel.com/dashboard
- 找到你的项目
- 点击进入
- 目前 Vercel 免费版没有"暂停"按钮，直接停止访问即可

### 删除（永久删除）
- 访问 https://vercel.com/dashboard
- 找到你的项目，点击进入
- 点击右上角 "Settings"
- 滚动到底部，找到 "Delete Project"
- 点击并确认删除
